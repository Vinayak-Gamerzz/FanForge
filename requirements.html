THE FORGE RULEBOOK

Before you start forging, know what makes a ship count.

FanForge is about building something which is yours. Read the requirements before you start, then take your fandom wherever you want.

What your ship needs

Build It Yourself

It must be your creation, not someone's copied

Make It Unique

Every ship should have it's own identity, don't simply copy another websitee

Web Based

It must be a website that everyone can open and experience

Visuals

Give it visual identity like images, cards, artwork, buttons, characters, or other media types

Interactive

it should have something that visitors can interact with like buttons, cards, 3js models, etc.

Your project must:

  • Be based around a fandom, character, universe, game, movie, show, or similar interest
  • Be a working website that can be opened and explore
  • Be your original Work
  • Include HTML, and CSS as the major part of it
  • Include atleast one visual element
  • Use multiple HTML, CSS elements throught the website (atleast 15 each)
  • Include atleast 3 interactive elements
  • Have readable text and elements
  • Have working links, buttons, and features
  • Be complete enough for someone else to understand and experience your idea

Before You Ship

  • Make sure your website is complete
  • Check that all your links and interactive features work
  • Make sure your project is genuinely your own
  • Check your website on different screen sizes
  • Make sure your submission follows the FanForge requirements

Forging Solo?

You don't need a club to ship in FanForge, if you're an individual creator you can ship it via individual submission form
